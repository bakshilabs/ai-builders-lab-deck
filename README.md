# AI Builders Lab · engagement deck

An animated HTML deck proposing how to build the AI Builders Lab together with ComputerXplorers, with the working prototype embedded.

**Open it:** https://bakshilabs.github.io/ai-builders-lab-deck/

- Arrow keys or Space move through the slides. O shows the overview, N the presenter notes, M toggles sound and F goes full screen.
- Slide 9 embeds the live prototype (`ai-builders-lab/`).

This is a published build. The source lives in a private repository.
